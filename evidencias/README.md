Esta pasta guarda as provas de que o nosso projeto funciona.

Ainda estamos no começo, então quase tudo aqui está pendente. Vamos
preenchendo conforme o sistema for rodando de verdade.

alteração, e o resultado foi verde.

![CI verde](02-ci-verde.png)

## O que ainda vamos colocar e como vamos preencher

- Vídeo: mostrando o projeto subindo e resolvendo uma issue do começo ao fim.
- Planilha: uma linha por issue, dizendo se resolveu e quanto gastou.
- Logs: os registros da execução, mostrando onde o sistema parou.
- Falhas: pelo menos 3 casos em que erramos, com o motivo e o que corrigimos.
- Histórico: print mostrando que os três participaram.

## Nossas regras

- Antes de subir qualquer print ou vídeo, conferimos se não aparece token,   senha ou dado pessoal.
- Os números daqui têm que ser os mesmos do trabalho escrito. Se a planilha   diz 55%, o texto diz 55%.
- Se o sistema acertar pouco, a gente mostra o número real e explica. Resultado ruim documentado vale mais que número bonito sem prova.
- Tudo tem que ser da versão final. Print de versão antiga não vale.
